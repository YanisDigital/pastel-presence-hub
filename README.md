# Анна Шевченко — лендинг психолога (демо)

Портфоліо-проєкт: односторінковий сайт психолога у стилі «Quiet Editorial». Персонаж, відгуки, адреса та контакти — вигадані; сайт працює в демо-режимі (`IS_DEMO` у `src/config.ts`): посилання на месенджери неактивні, форма запису нікуди не надсилає дані, сторінка закрита від індексації пошуковиками.

**Live:** https://yanisdigital.github.io/pastel-presence-hub/

## Навіщо саме так — маркетинговий погляд

Дизайн навмисно уникає типового «AI-wellness»-шаблону — яскравих ілюстрацій, круглих аватарок і однакових бірюзових кнопок, які зустрічаються на десятках сайтів психологів. Натомість тут тепла паперова палітра, шрифт Fraunces із м'яким, злегка рукописним контуром замість корпоративної стерильності, і майже непомітна анімація — «дихання» кнопки запису, повільний паралакс, поетапна поява блоків при скролі. Усе це працює на одну мету: знизити тривожність відвідувача ще до першого речення тексту, що критично для ніші психологічної допомоги, де рішення довіритися формується враженням від сайту в перші секунди. Асиметрична розкладка розділу «Підхід» і редакційна типографіка сигналізують експертність без зайвого «глянцю», а чесний демо-банер і неактивні контакти прямо кажуть: це вітрина навичок, а не діючий кабінет. Мета сторінки — показати, що такий рівень уваги до деталей можна замовити.

## Стек

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui (Radix) · Fraunces + Manrope · UA/RU локалізація

## Запуск

```bash
npm ci
npm run dev
```

`npm run build` — продакшн-збірка в `dist/`, `npm test` — vitest, `npm run lint` / `npm run typecheck` — перевірки якості коду.

## Деплой

Пуш у `main` запускає workflow `.github/workflows/deploy.yml`, який збирає сайт і публікує його на GitHub Pages; `.github/workflows/ci.yml` перевіряє кожен pull request (lint, typecheck, тести, збірка). Базовий шлях `/pastel-presence-hub/` заданий у `vite.config.ts`; при перенесенні на інший домен поміняйте його і абсолютний `og:image` в `index.html`.
